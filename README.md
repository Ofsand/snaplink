# Snaplink

> A production-style URL shortener with link management, fast redirection, and click analytics.

🚧 **Status:** in development

## Tech stack

**Backend:** Java 21 · Spring Boot 4 · Spring Security (JWT) · Spring Data JPA · PostgreSQL · Flyway · Redis

**Frontend:** React 19 · TypeScript · Vite · TanStack Query · React Router · Zustand

**Testing:** JUnit 5 · Mockito · Testcontainers · Vitest · React Testing Library

**DevOps:** Docker · Docker Compose · GitHub Actions
